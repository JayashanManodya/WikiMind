### Overview
IKMS is a Retrieval-Augmented Generation (RAG) document question-answering system developed by Jayashan that enables users to upload PDFs and receive accurate, context-aware answers. It uses a multi-agent pipeline for query planning, document retrieval, answer generation, and verification.
