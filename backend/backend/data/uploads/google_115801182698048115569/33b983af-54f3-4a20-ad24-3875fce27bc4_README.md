## 📌 Executive Summary

**KIKO** (Kapuruka Shopping Agent) is an advanced, production-grade conversational commerce engine built specifically for **Kapruka** (Sri Lanka's leading e-commerce platform). It converts traditional e-commerce browsing into a fluid, multi-agent conversational experience. 

By seamlessly integrating **LangGraph multi-agent orchestration**, **Model Context Protocol (MCP)**, **FastAPI**, and a **Next.js 16 / React 19 dynamic JSON UI rendering engine**, KIKO enables users to search for products, check stock, validate delivery availability across Sri Lankan cities, manage shopping carts, build order summaries, execute guest checkouts, and track live order status—all through natural dialogue in 5 supported language formats.

---

## 🌟 Key Features & Capabilities

- 🤖 **Multi-Agent Orchestration**: Powered by **LangGraph**, utilizing a Supervisor-Worker pattern to route intents dynamically between specialized worker agents (Search, Checkout, Tracking).
- 🔌 **Native MCP (Model Context Protocol) Integration**: Direct streamable HTTP connection (`https://mcp.kapruka.com/mcp`) interfacing directly with Kapruka's internal product catalog, inventory, delivery, and order tracking systems.
- 🗣️ **Multilingual & Code-Mixed Intelligence**: Native handling of:
  - **English**
  - **Sinhala (Unicode)** (e.g. *"මට චොකලට් කේක් එකක් ඕනේ"*)
  - **Singlish (Romanized Sinhala)** (e.g. *"Mata birthday cake ekak hoyala denna"*)
  - **Tamil (Unicode)** (e.g. *"எனக்கு ஒரு கேக் வேண்டும்"*)
  - **Tanglish (Romanized Tamil)** (e.g. *"Enakku cake venum"*)
- 🎨 **Dynamic JSON UI Protocol**: Instead of returning raw unstructured text, the backend returns strongly typed Pydantic payloads (`AgentResponse`). The React frontend parses these JSON objects into rich interactive widgets (`ProductGrid`, `ProductDetailCard`, `CartWidget`, `CheckoutForm`, `Invoice`, `SuccessCard`, `TrackingCard`).
- 🛡️ **Safety Guardrails & Order Verification**: Strict validation on future delivery dates, city availability checks, and mandatory explicit user confirmation before placing actual orders.
- 🛒 **Context-Aware Stateful Cart**: Client-side & session-level cart state seamlessly passed into AI prompts for accurate calculations and instant updates.

## 🧠 AI Multi-Agent Architecture (LangGraph)

KIKO's core AI intelligence is implemented in `backend/app/core/agents/agent.py` using **LangGraph**:

1. **Supervisor Agent**: The central router. Inspects incoming user messages and session history to classify intent and direct control to the appropriate worker.
2. **Search Agent**:
   - **Tools**: `search_products`, `get_categories`, `get_product`, `manage_cart`
   - **Responsibilities**: Fixes search query typos, translates native queries to English, queries Kapruka's product database, presents rich product cards/grids, and handles cart additions/removals.
3. **Checkout Agent**:
   - **Tools**: `list_delivery_cities`, `check_delivery`, `create_order`
   - **Responsibilities**: Prompts for recipient and delivery details, validates target delivery cities and future delivery dates, renders order summaries, enforces double-confirmation guardrails (`user_confirmed=True`), and issues guest checkout links.
4. **Tracking Agent**:
   - **Tools**: `track_order`
   - **Responsibilities**: Retrieves live status, fulfillment timelines, payment information, and delivery tracking for existing Kapruka order numbers.

## 🔌 Kapruka MCP Toolset Reference

KIKO connects to Kapruka's Model Context Protocol (MCP) server at `https://mcp.kapruka.com/mcp` using streamable HTTP transport:

| MCP Tool Name | Tool Wrapper | Function & Purpose |
| :--- | :--- | :--- |
| `kapruka_list_categories` | `get_categories` | Fetches Kapruka category hierarchy and subcategories. |
| `kapruka_search_products` | `search_products` | Filters purchasable products by keyword, category, price bounds, and stock. |
| `kapruka_get_product` | `get_product` | Retrieves complete product metadata, high-res images, variants, and stock status. |
| `kapruka_list_delivery_cities` | `list_delivery_cities` | Searches and returns valid delivery locations across Sri Lanka. |
| `kapruka_check_delivery` | `check_delivery` | Verifies delivery feasibility for specific cities, dates, and products. |
| `kapruka_create_order` | `create_order` | Generates a guest checkout payload and returns payment gateway checkout URLs. |
| `kapruka_track_order` | `track_order` | Provides real-time order status, payment status, and delivery timeline metrics. |

## 🖼️ JSON UI Protocol (Backend -> Frontend)

Instead of plain text responses, the backend outputs structured JSON conforming to `AgentResponse` (defined in `backend/app/models/response_models.py`). The Next.js frontend dynamically renders corresponding React components:

| Discriminator `type` | Backend Pydantic Model | Frontend Rendered Component | UI Experience |
| :--- | :--- | :--- | :--- |
| `text` | `TextResponse` | `<ChatBubble />` | Conversational text bubble supporting Markdown & native scripts. |
| `recommended_items` | `RecommendedItemsResponse` | `<ProductGrid />` | Interactive product carousel / grid with price & image previews. |
| `product_detail` | `ProductDetailResponse` | `<ProductDetailCard />` | Rich product showcase card with images, description, & "Add to Cart". |
| `list_categories` | `ListCategoriesResponse` | `<CategoryList />` | Expandable category chips and navigation tree. |
| `cart_update` / `read_cart`| `CartUpdateResponse` / `ReadCartResponse` | `<CartWidget />` | Interactive shopping cart summary with quantity adjusters. |
| `checkout_form` | `CheckoutFormResponse` | `<CheckoutForm />` | Embedded form collecting phone, address, city, date, and gift notes. |
| `order_summary` | `OrderSummaryResponse` | `<Invoice />` | Detailed pre-checkout itemized invoice requiring explicit confirmation. |
| `order_created` | `OrderCreatedResponse` | `<SuccessCard />` | Celebratory order confirmation card with direct secure payment link. |
| `track_order` | `TrackOrderResponse` | `<TrackOrderCard />` | Live order timeline status, delivery address, and payment indicators. |

## 💻 Tech Stack

### Frontend
- **Framework**: Next.js 16 (App Router)
- **UI Library**: React 19
- **Language**: TypeScript
- **Styling**: Custom Vanilla CSS Design System (`globals.css`), Responsive Flex/Grid Tokens
- **Icons**: Lucide React
- **Auth**: NextAuth.js

### Backend
- **Framework**: FastAPI (Python 3.14+)
- **Server**: Uvicorn
- **AI / LLM Orchestration**: LangChain, LangGraph, OpenAI (`gpt-4o` / `gpt-5-mini`), Groq
- **Protocol**: Model Context Protocol (MCP) Client (`mcp` package)
- **Data Models**: Pydantic v2 & SQLModel
- **Package Manager**: `uv`

## 🛠️ Prerequisites & Installation

### Prerequisites
- **Node.js**: `v20.0.0` or higher
- **Python**: `v3.14` or higher
- **uv**: Fast Python package installer (`pip install uv` or `curl -LsSf https://astral.sh/uv/install.sh | sh`)

---

### 1. Backend Setup (FastAPI + LangGraph)

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```

2. Install dependencies with `uv`:
   ```bash
   uv sync
   ```

3. Create a `.env` file inside the `backend/` directory:
   ```env
   SERVER_URL="https://mcp.kapruka.com/mcp"
   OPENAI_API_KEY="your_openai_api_key"
   GROQ_API_KEY="your_groq_api_key_optional"
   LLM_MODEL="gpt-4o"
   ALLOWED_ORIGINS="http://localhost:3000"
   LOG="True"
   ```

4. Start the backend development server:
   ```bash
   uv run main.py
   ```
   *The API will be available at `http://localhost:8000` (Health check: `http://localhost:8000/health`).*

---

### 2. Frontend Setup (Next.js 16)

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install NPM dependencies:
   ```bash
   npm install
   ```

3. Create a `.env` file inside the `frontend/` directory:
   ```env
   NEXT_PUBLIC_API_URL="http://localhost:8000"
   NEXTAUTH_URL="http://localhost:3000"
   NEXTAUTH_SECRET="your_nextauth_secret_hash"
   ```

4. Launch the frontend development server:
   ```bash
   npm run dev
   ```
   *The web app will be accessible at `http://localhost:3000`.*
